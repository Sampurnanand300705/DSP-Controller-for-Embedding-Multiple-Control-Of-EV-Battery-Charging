## Abstract

This project presents a **DSP-based control system for EV battery charging using multiple power converter control strategies**. The proposed system integrates renewable energy, power electronic converters, and real-time digital control to achieve efficient and reliable battery charging. In the first stage, a **DC–DC Boost Converter** is interfaced between a solar PV array and an EV battery, while a **Perturb and Observe (P&O) MPPT algorithm** is implemented on the **TMS320F28379D DSP** to extract maximum available power from the PV source. The DSP continuously acquires PV voltage and current through ADC channels, calculates the power, and adjusts the converter duty cycle using PWM signals.

The system is further extended with a **Phase-Shift Full-Bridge (PSFB) converter** for high-power EV charging. Phase-shift control with voltage and current feedback enables regulated power transfer, while soft-switching operation helps reduce switching losses. The proposed DSP platform provides high-speed processing, precise PWM generation, real-time monitoring, and a modular architecture for integrating multiple control functions. Experimental results demonstrate **97.8% average efficiency for the P&O MPPT stage** and effective PSFB converter operation, highlighting the potential of the proposed system for efficient and reliable EV charging applications.
